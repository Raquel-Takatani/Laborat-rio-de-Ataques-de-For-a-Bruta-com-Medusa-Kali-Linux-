# Laborat-rio-de-Ataques-de-For-a-Bruta-com-Medusa-Kali-Linux-
Laboratório prático de pentest com Kali Linux e Medusa, simulando ataques de força bruta e password spraying contra FTP, um formulário web (DVWA) e SMB em ambiente virtual isolado (Metasploitable 2), com documentação completa de comandos, wordlists e recomendações de mitigação.
